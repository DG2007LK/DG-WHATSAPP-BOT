HOW TO GET YOUR PAIR CODE

  1. Tap the GET BOT PAIR button above.
  2. Enter your WhatsApp number with country code — e.g. 9476XXXXXXX (no + and no leading 0).
  3. Press Generate Code and wait a few seconds while we create your code.
  4. Tap the Copy button to copy your 8-digit pairing code.
  5. Open WhatsApp → Settings → Linked Devices → Link a Device.
  6. Choose Link with phone number and paste the code.
  7. Done! Your bot is now connected ✅
